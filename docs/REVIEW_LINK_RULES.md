# 역량평가 문제 ↔ 복습 영상 연결 규칙

문제마다 복습 영상 구간을 정할 때 사람마다 판단이 달라지지 않도록 아래 기준을 따른다.

## 연결 기준 (사람이 정할 때)

1. **처음 설명한 구간을 대표로 한다.** 같은 개념이 여러 날 나오면, 개념을 처음 설명한 강의·시점을 연결한다.
2. **시작 시각은 설명이 시작되는 문장에 맞춘다.** 자막에서 키워드가 몰린 구간을 찾고, 그 설명이 시작하는 문장으로 몇 초 당긴다.
3. **정확한 시점을 못 찾으면 직접 연결하지 않는다.** 아래 "개념 기본값"이 대신 보여준다.
4. **수업(교안·자막)에서 다루지 않은 내용은 연결하지 않는다.** "연결된 복습 영상 없음"으로 둔다.
5. 날짜는 커리큘럼 교안의 강의일과 맞는지 확인한다.

## 개념 기본값 (서버가 자동으로)

`GET /api/assessments/{id}/review-guide`의 `reviewLinks[].matchType`

| matchType | 의미 | 화면 표시 예 |
|---|---|---|
| `QUESTION` | 문제에 직접 연결한 구간 | "복습하기 (3:32)" |
| `TOPIC` | 직접 연결이 없어서, 같은 핵심 개념(`topic`)의 구간 중 **가장 먼저 나온 것** 1개를 대신 보여줌 | "같은 개념 강의 보기 (10/21 1교시)" |

- 직접 연결이 있으면 `TOPIC`은 나오지 않는다.
- 문제에 개념 분류가 없거나, 그 개념에 등록된 구간이 없으면 빈 목록 + "연결된 복습 영상 없음".
- 공개 범위 규칙(해설 공개 후, 같은 기수, PUBLIC·미삭제 영상)은 두 경우 모두 같다.
- 구간(`lecture_chapters`)에 `topic_id`를 지정해야 개념 기본값으로 쓰인다.
